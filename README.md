# Edu-Video AI Pipeline

This folder contains a portfolio-ready snapshot of my final year project: an AI-powered educational video generation pipeline.

## What the project does

The system combines:
- PDF and slide input processing
- visual asset extraction and retrieval
- LLM-powered script generation
- avatar and TTS integration
- optional PowerPoint deck generation
- evaluation metrics for generated content

## Why this is a strong portfolio project

It demonstrates skills in:
- Python application development
- AI system orchestration
- multimodal pipelines
- prompt engineering
- backend modularity and configuration design
- end-to-end experimentation and evaluation

## Folder structure

- src/ — main application and pipeline code
- docs/ — architecture and usage notes
- examples/ — prompt and script examples
- assets/ — screenshots or demo media you can add

## Quick start

1. Create a Python environment
2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
3. Update model and runtime paths in src/config.py if needed
4. Launch the UI:
   ```bash
   python src/app.py
   ```

## Notes

- This portfolio version keeps the core code and documentation while avoiding large generated outputs and raw backup files.
- Local model paths and environment-specific runtime settings may need adjustment on your machine.
